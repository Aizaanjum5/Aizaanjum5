### 🔬 Research and Ongoing Work

* 🩺 Algorithmic Detection of Dependency Conflicts in Medical Workflows (Talent UD / DETEP) involving graph-based algorithmic frameworks to identify and resolve dependency conflicts and constraint violations in multi-step medical treatment protocols.
* 🦷 Deep Learning for Early Detection of Dental Caries focusing on computer vision architectures and CNNs for automatic feature extraction, data augmentation, and classification of early-stage dental caries from diagnostic imagery.
* 📦 How Bug Fixes Propagate in the NPM Ecosystem (Co-Author, Under Review) covering empirical software engineering research at Nicolaus Copernicus University (TSSP) analyzing bug fix propagation through multi-tiered software package ecosystems via dependency graph parsing.
